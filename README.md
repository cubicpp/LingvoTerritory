# 語疆 · LingvoTerritory

> 感谢 [MCPDict](https://github.com/osfans/MCPDict) 提供设计灵感和部分数据来源。本项目是《数据可视化》课程的大作业，现以开源方式分享。欢迎更多人加入语言开源社区，一起记录和探索语言的多样性。
>
> 前端主要由 DeepSeek 协助完成。内容受限于原始资料的覆盖范围、采集时间与标注口径，也可能受到不同学术观点和数据处理方式的影响，因此存在疏漏或事实性错误。
>
> 本项目不再维护。

語疆是一个探索汉语方言、历史音韵和汉字材料的交互式平台。

在线体验：[lingvoterritory.netlify.app](https://lingvoterritory.netlify.app/)

## 快速开始

```bash
npm install
npm run dev
```
## 视图体系

### 空间格局

| 视图     | 研究问题                                 | 可视化重点                                                   |
| -------- | ---------------------------------------- | ------------------------------------------------------------ |
| 地理分布 | 方言点如何在地理空间中聚集、扩散与缺席？ | 地图点位、密度/覆盖阅读、方言大类图例、覆盖偏差提示          |
| 区域统计 | 不同区域的数据覆盖是否均衡？             | 大类样本数、地理跨度、核心省份、覆盖率                       |
| 方言距离 | 地理相近是否意味着语音相近？             | 地理 MDS、语音 MDS、密度等高线、圆形聚合、离群点和类内离散度 |

### 分类结构

| 视图     | 研究问题                           | 可视化重点                                   |
| -------- | ---------------------------------- | -------------------------------------------- |
| 分类谱系 | 传统分类体系如何组织方言谱系？     | 径向树、矩形树、分类层级规模                 |
| 层次聚类 | 算法聚类在多大程度上支持既有大类？ | 声韵调聚类树、分支纯度、混杂分支、分类稳定性 |
| 亲疏关系 | 哪些方言大类共享最多文字材料？     | 弦图、关系强度排行、共享字共现关系           |

### 音韵结构

| 视图     | 研究问题                             | 可视化重点                                        |
| -------- | ------------------------------------ | ------------------------------------------------- |
| 音韵分析 | 中古与近代音系中哪些声韵组合最密集？ | 声母-韵摄热力矩阵、高频格、结构性空白、声母组分区 |
| 音韵覆盖 | 音韵调查覆盖在哪些格位上更完整？     | 调查字表覆盖矩阵、缺口定位                        |
| 音韵流图 | 声母与韵摄之间的流量结构如何形成？   | 桑基图、合并/细分切换、Top flows、标签避让        |
| 音系对比 | 声韵调指标如何共同区分方言大类？     | 平行坐标、声韵调三维比较                          |
| 声调曲线 | 典型调型在不同方言大类中如何比较？   | 五度制小多重图、参考线、典型调型比较              |

### 工具检索与文字材料

| 视图     | 研究问题                           | 可视化重点                                     |
| -------- | ---------------------------------- | ---------------------------------------------- |
| 特征文字 | 哪些字既高频又真正具有方言辨识度？ | 词云、高频字、TF-IDF 式区分度字、Pareto 集中度 |
| 汉字分析 | 单字读音在不同材料中如何互证？     | 读音查询、历史演变、女书、CJK、编码、拟音对比  |
| 字符探源 | 汉字部件如何连接字形材料？         | IDS 部件分解、部件-汉字矩形树                  |
| 历史演变 | 字音如何在历史层中演化？           | 历史音系材料与字音层次                         |
| 江永女书 | 女书材料如何进入文字比较视野？     | 女书字符和汉字材料对照                         |
| 汉日韩越 | 汉日韩越读音如何形成跨语言对照？   | Unihan / CJKV 读音比较                         |
| 编码透视 | 编码系统如何改变文字检索方式？     | 输入法、编码、异体字与字符信息                 |
| 拟音对比 | 拟音系统之间如何对齐与差异化？     | 上古、中古、近代拟音材料对比                   |

## 数据来源

- [MCPDict（汉字音典）](https://github.com/osfans/MCPDict)：方言点、读音、韵书、字书及字形资料。
- [小学堂](https://xiaoxue.iis.sinica.edu.tw/)：历史音韵与各地方言材料。
- [汉语方言 Lexibank 数据集](https://github.com/lexibank/beidasinitic)：CLDF 语言与词形数据。
- [PHOIBLE](https://github.com/phoible/dev)：音系资料。
- [Glottolog](https://glottolog.org/)：语言分类资料。
- [Unicode Unihan 数据库](https://www.unicode.org/charts/unihan.html)：汉字及跨语言读音资料。
- [阿里云 DataV 地理数据](https://datav.aliyun.com/portal/school/atlas/area_selector)：地图边界数据。
